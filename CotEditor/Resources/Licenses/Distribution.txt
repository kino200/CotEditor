This installer contains maEditor and the MarkAny DocumentSafer editor bridge.
It does not contain policy servers, credentials, document keys, sample policy,
DocumentSafer manager, or the vendor DRM dylib. Protected TXT operation requires
a compatible signed DocumentSafer manager configured for this editor ID:
com.markany.securedocs.textedit, editor protocol 6.
A manager built for the former com.markany.DocumentSaferText identity must be
updated together with the bridge; authentication is never weakened as fallback.

Without a manager installed or running, ordinary TXT editing is available.
Standalone use does not encrypt or decrypt documents. Encrypted inputs require
DocumentSafer. Failure of an existing managed session never enables plaintext
saving as a fallback.
