# maEditor 단독 TXT 편집 계획

2026-11-17. 사용자가 DocumentSafer 없이 maEditor를 실행하도록 요청했으며, 단독 사용 시 암호화·복호화를 하지 않도록 명시했다.

1. 새 문서도 무조건 관리앱 정책을 조회하는 원인을 수정한다. 실제 설치/실행된 관리앱이 없으면 일반 TXT만 열고 저장하며 브리지는 호출하지 않는다.
2. 관리앱은 표준 시스템/사용자 Applications의 설치본과 실행 중인 앱으로 판별한다. 등록만 남은 개발·백업 번들과 연결 도구 단독 잔존은 설치 근거로 사용하지 않는다. 운영/데몬/시험 앱의 정식 설치 위치도 확인한다.
3. 암호화 문서는 관리앱 없이는 열지 않는다. 관리앱을 감지했던 서비스는 해당 세션에서 관리 상태를 유지하며 제거·종료·로그인/서명/정책 실패를 평문 저장으로 바꾸지 않는다. 매 저장 시 새 설치와 정책 변경도 다시 확인한다.
4. 새 일반 문서·기존 TXT 편집 왕복·빈 파일·인코딩 보존·암호문 거부·암복호화 미호출·관리 상태 전환/실패 보존을 회귀로 검증한다. 설치 판별의 개발 백업 제외도 시험한다.
5. 일반 TXT 상태 문구와 배포 안내를 갱신하고 서명 빌드 및 실제 단독 실행을 확인한다. 기존 보호 UI의 반출 제한과 암호화 문서 파일 경계는 유지한다. 커밋·push·기존 앱 교체는 별도 요청이 없으므로 수행하지 않는다.

2026-11-17 후속 요청. 사용자가 현재 codex/documentsafer-memory-txt 브랜치에 단독 실행 지원 변경을 커밋하도록 승인했다. 소스·회귀·사용 안내·검증 기록을 한 기능 커밋으로 남기고 Git 상태를 확인한다. push와 기존 앱 설치는 포함하지 않는다.
